随机变量

本章节主要梳理一元的随机变量

分布函数及概率函数

随机变量

随机变量即映射，该映射对每一个ω输出一个实值X(ω)。

$ X : \Omega \rightarrow \mathbb{R} $

如：令X(ω)表示序列中出现正面的次数，某次抛硬币的结果为：ω = HHHTTTHHHT，则X(ω)=6。

分布函数和概率函数

  • 累积分布函数（CDF）
    用于描述事件 $X \leq x$ 的概率。

    表示函数$F_X : \mathbb{R} \rightarrow [0,1] $，其定义为：
    $F_X(x) = \mathbb{P}(X \leq x)$

  • 分位数函数（逆CDF）
    用于根据给定的累计概率 $q$，反推出对应的随机变量取值 $x$

    令X为一个随机变量，其CDF为F，则逆CDF为：
    $F^{-1}(q) = inf {x:F(X)>q}$，其中，$q \in [0,1]$如果F严格递增并且连续则$F^{-1}(q)$是满足$F(x) = q$的唯一实数$x$
    称$F^{-1}(1/4)$为第一分数，$F^{-1}(1/2)$为中位分数，$F^{-1}(3/4)$为第三分数。

  • 概率质量函数（PMF）
    用于描述离散随机变量下的概率分布质量。

    对于离散随机变量 $X$，定义：
    $p_X(x)=\mathbb{P}(X=x)$
    对于事件 $X\in A$，有：
    $\mathbb{P}(X\in A)=\sum_{x\in A}p_X(x)$

  • 概率密度函数（PDF）
    用于描述连续随机变量下概率分布的密度。对任意有意义的x，f(x)=0（PDF描述密度，单点密度为零）

    如果存在某个函数$f_X(x) \geq 0, \int_{-\infty}^{\infty} f_X(x)dx = 1$
    并对任意的$a \leq b$有：

$\mathbb{P}(a < X < b) = \int_{a}^{b} f_X(x)dx$

则称随机变量X是连续型随机变量，函数$f_X$称为概率密度函数(PDF)，且有：

$F_X(x) = \int_{-\infty}^{x} f_X(t)dt$, 以及$f_X(x) = F’_X(x)$在$F_X$可微的点均成立。

重要的离散随机变量

注： 通常用 $ X \sim F $ 表示X服从分布F。

  • 单点分布
    仅在一个点a上有概率质量，记为$X \sim \sigma_a$ 即$\mathbb{P}(X=a)=1$，那么
    $
    f(x) =
    \begin{cases}
    1, x = a\
    0, 其他
    \end{cases}
    $

  • 离散均匀分布
    令$k > 0$为给定的整数，假设$X$具有如下概率质量函数：

$
f(x) =
\begin{cases}
1/k, x = 1,2,…,k\
0, 其他
\end{cases}
$

则称$X$在${1,2,…,k}$上服从均匀分布。

  • 伯努利分布（零一分布）
    令X表示实验结果，用0，1表示，则

$\mathbb{P}(X=1)=p,P(X=0)=1-p$,其中
$p \in [0,1]$

则称为X服从伯努利分布，记为$X \sim Bernouli(p)$

PMF为

$f(x) = p^x (1-p)^{1-x}$ $x \in \left{0,1\right}$

  • 二项式分布
    假设抛一枚硬币出现正面的概率为 p，其中0 ≤ p ≤ 1. 将这枚硬币抛n次,令X表示出现正面的次数,假设每次抛是相互独立的,令f(x)=P(X=x) 为概率密度函数，易得

$
f(x) =
\begin{cases}
\binom{n}{x} p^x (1-p)^{n-x}, & x = 0,1,\ldots,n, \
0, & \text{其他}.
\end{cases}
$

  • 几何分布
    如果

$P(X = k) = (1-p)^{k-1}p, k=1,2,3,…$

则X服从参数为$p \in (0,1)$的几何分布，记为$X \sim Geom(p)$

  • 泊松分布
    如果

$f(x) = e^{- \lambda} \frac{\lambda^x}{x}, x \geq 0$

则X服从参数为$p \in (0,1)$的几何分布，记为$X \sim Geom(p)$

重要的连续随机变量

  • 均匀分布
    若：

$
f_X(x)=
\begin{cases}
\frac{1}{b-a}, & a\leq x\leq b
0, & \text{其他}
\end{cases}
$

则称 $X$ 在 $[a,b]$ 上服从均匀分布，记为：
$X\sim U(a,b)$

  • 正态（高斯）分布

若：

$f_X(x)=\frac{1}{\sqrt{2\pi}\sigma}\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$

则称 $X$ 服从均值为 $\mu$、方差为 $\sigma^2$ 的正态分布，记为：

$X\sim N(\mu,\sigma^2)$

  • 指数分布

若：

$
f_X(x)=
\begin{cases}
\lambda e^{-\lambda x}, & x\geq 0
0, & x<0
\end{cases}
$

其中 $\lambda>0$，则称 $X$ 服从参数为 $\lambda$ 的指数分布，记为：

$X\sim Exp(\lambda)$

  • 柯西分布

标准柯西分布的概率密度函数为：

$f_X(x)=\frac{1}{\pi(1+x^2)}$

  • $\chi^2$分布
    设 $Z_1,Z_2,…,Z_k$ 相互独立，且均服从标准正态分布：

$Z_i\sim N(0,1)$

若：

$X=Z_1^2+Z_2^2+\cdots+Z_k^2$

则称 $X$ 服从自由度为 $k$ 的 $\chi^2$ 分布，记为：

$X\sim \chi_k^2$

二元分布

给定两个随机变量X和Y，

其PDF(没区分PDF和PMF)为：$f(x,y) = \mathbb{P}(X=x,Y=y)$ 或 $f_{X,Y}$

其CDF为：$F_{X,Y} = \mathbb{P}(X \leq x,Y \leq y)$

如$(X,Y)$具有联合密度函数$f_{X,Y}$，则$X$的边际概率密度函数为：
$f_X(x) = \mathbb{P}(X=x) = \sigma _y \mathbb{P}(X=x,Y=y) = \sigma _y f(x,y)$

对连续随机变量：
$F_X = f_X(x) = \int f(x,y) dy$

多元分布

给定多个随机变量：

$\mathbf{X}=(X_1,X_2,…,X_n)$

其联合分布记为：

$f_{X_1,…,X_n}(x_1,…,x_n)$

通过对其他变量求和或积分，可以得到某一个变量的边际分布。

例如：

$f_{X_1}(x_1)
\sum_{x_2,…,x_n}
f_{X_1,…,X_n}(x_1,…,x_n)$

连续情况下将求和换成积分。

如果 $X_1,…,X_n$ 相互独立，则：

$f_{X_1,…,X_n}(x_1,…,x_n)
\prod_{i=1}^{n}f_{X_i}(x_i)$
